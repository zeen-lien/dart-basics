# Pertemuan 1 - Dasar Dart

Folder ini berisi tugas latihan untuk pertemuan pertama mata kuliah Pemrograman Mobile.

## Materi yang Dipelajari

1. **Tipe Data** - String, int, double, bool, List, Map, dll
2. **Variabel** - Deklarasi dan penggunaan variabel
3. **Operator** - Aritmatika, Relasional, Logika
4. **Input dari User** - Menggunakan `dart:io`
5. **Percabangan** - if-else, switch-case
6. **Perulangan** - for, while, do-while, for-in

## Daftar Tugas

### Tugas Latihan 1 (Dasar-Dasar Dart)
- `latihan1_soal1.dart` - Mencetak nama
- `latihan1_soal2.dart` - String dengan kutip tunggal dan ganda
- `latihan1_soal3.dart` - Deklarasi konstanta
- `latihan1_soal4.dart` - Menghitung bunga sederhana
- `latihan1_soal5.dart` - Menghitung persegi/kuadrat angka
- `latihan1_soal6.dart` - Menggabungkan nama depan dan belakang
- `latihan1_soal7.dart` - Hasil bagi dan sisa pembagian
- `latihan1_soal8.dart` - Menukar dua bilangan
- `latihan1_soal9.dart` - Menghapus spasi dari string
- `latihan1_soal10.dart` - Konversi String ke int
- `latihan1_soal11.dart` - Pembagian tagihan restoran

### Tugas Latihan 2 (Percabangan & Perulangan)

## Cara Menjalankan

Untuk menjalankan setiap file, gunakan perintah:

```bash
dart run dart_project/bin/pertemuan1/nama_file.dart
```

Contoh:
```bash
dart run dart_project/bin/pertemuan1/latihan1_soal1.dart
```
